# 달빛다방 ☕ — 친구들과 만나는 실시간 온라인 카페

브라우저 하나로 들어가는 작은 2D 가상 카페. 친구들이 **같은 초대 링크**로 접속하면 아바타 이동, 채팅, 감정 표현, 음료, 앉기가 실시간 동기화됩니다.

## 실행하기

**Node.js 20 이상**이 설치된 PC에서 이 폴더를 열고 아래 명령어를 실행하세요.

```bash
npm start
```

브라우저에서 `http://localhost:3000`에 접속합니다. `index.html`을 더블클릭하면 오프라인 미리보기만 사용할 수 있으며 친구들과 접속하려면 서버가 필요합니다.

## 친구들과 인터넷에서 만나기 (배포)

1. 이 폴더의 파일을 새 GitHub 저장소에 업로드합니다 (`server.js`, `package.json`, `public/`, `render.yaml`).
2. [Render](https://render.com)에서 **New → Web Service**를 만들고 GitHub 저장소를 연결합니다.
3. Runtime은 Node, Build Command는 `echo No build needed`, Start Command는 `npm start`로 지정합니다. 이 프로젝트는 npm 외부 패키지를 설치하지 않습니다.
4. Render에서 발급된 `https://...onrender.com` 주소로 접속합니다. 닉네임을 입력하고 방 코드를 비워두면 새 방이 만들어집니다.
5. 카페 화면의 **친구 초대하기**를 누르면 `?room=XXXXXX`가 포함된 링크가 복사됩니다. 친구가 링크를 열고 닉네임만 입력하면 같은 공간에 들어옵니다.

Render 무료 플랜의 제공 여부·정책은 변동될 수 있으며, 무료 서버는 유휴 시 절전 모드로 전환되어 첫 접속이 지연될 수 있습니다. 다른 Node.js 웹 호스팅 서비스에도 배포할 수 있습니다.

**같은 와이파이**에서 먼저 실험하려면 서버 PC의 로컬 IP (`http://192.168.x.x:3000`)를 친구에게 보내세요. 공유기 및 OS 방화벽 설정이 허용되어야 합니다. 외부 인터넷에서는 공개 서버에 배포해야 합니다.

## 조작

- PC: **WASD / 방향키**로 이동하거나 카페 바닥을 클릭
- 모바일: 카페 바닥을 탭하거나 방향키 조작
- 앉기: 빈 의자 자동 선택, 다시 누르면 일어나기
- 음료 주문: 4가지 무료 가상 음료
- 인사/하트/짠: 주변 친구에게 이모지 표시
- 채팅: 같은 방 인원에게 메시지가 실시간 전달됨
- 분위기 소리: 브라우저에서 생성하는 작은 신스 패드와 빗소리 (저작권 음원 사용 안 함)

## 현재 제한사항

- 친구 **최대 24명/방**. 방은 코드를 아는 사람이 들어올 수 있습니다 (비밀번호/계정/관리자 기능 없음).
- 실시간 채팅 최근 60개만 메모리에 유지됩니다. 서버를 재시작하면 방, 메시지와 이용자 정보가 사라집니다.
- 간단한 WebSocket 동기화 방식으로, 서버가 잠시 꺼지면 끊어집니다. 연결이 끊기면 새로고침하면 됩니다.
- 음성 채팅, 캐릭터 외형 변경, 영구 저장, 관리자 차단 기능은 아직 제공하지 않습니다.
- 배포용 서비스로 확장하려면 접근 제한, 관리 기능, 로깅/모니터링, 악용 방지 등을 추가하는 것이 좋습니다.

## 파일

- `server.js`: Node.js HTTP + WebSocket 서버 (외부 의존성 없음)
- `public/index.html`: 기본 웹 화면
- `public/styles.css`: 반응형 UI 스타일
- `public/app.js`: 카페 렌더링·모바일 조작·실시간 동기화
- `render.yaml`: Render 배포 설정 참고
