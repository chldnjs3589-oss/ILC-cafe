# ILC 카페 ☕ v2 — 모바일 실시간 채팅

친구들이 휴대폰과 PC로 같은 주소에 들어와 움직이고 바로 이야기할 수 있는 실시간 온라인 카페입니다.

## 기존 Render 웹사이트 업데이트

1. ZIP 압축을 해제하세요.
2. GitHub에서 **이미 연결한 저장소**의 **Code → Add file → Upload files**로 이동하세요.
3. 압축을 해제한 `ILC-cafe` 폴더 안의 **`public` 폴더, `package.json`, `server.js`, `render.yaml`, `README.md`**를 저장소 루트에 업로드하세요.
4. 기존 파일을 덮어쓰는 변경 사항을 확인하고 **Commit changes**를 누르세요.
5. Render에서 자동 배포가 켜져 있으면 곧 변경사항이 반영됩니다. 아니라면 **Manual Deploy → Deploy latest commit**을 클릭하세요.
6. **기존 Render 주소 그대로 사용**하면 됩니다. 앱 이름을 바꿨다고 Render 웹주소를 바꿀 필요는 없습니다.
7. 모바일에서 변경 전 화면만 계속 보이면 새로고침하거나 브라우저 캐시를 비워주세요.

**주의:** GitHub 최상위에 `package.json`이 직접 보여야 한다면, `ILC-cafe` 폴더 자체를 업로드하지 말고 폴더 **안의** 파일을 업로드하세요. 기존 저장소가 하위 폴더를 Root Directory로 설정한 형태라면, 해당 하위 폴더에 파일을 업로드해야 합니다. Render의 Root Directory는 GitHub 파일 위치와 일치해야 합니다.

## 로컬 테스트

Node.js 20+ 설치 후 ZIP 압축을 해제한 `ILC-cafe` 폴더에서 `npm start` 실행 → `http://localhost:3000` 열기.

## 모바일 조작

- 휴대폰 화면 위쪽에 카페가 나오고 **채팅 내용 + 채팅 입력창이 바로 아래에 항상 표시**됩니다.
- 입력창을 탭해 바로 채팅하세요. 다른 페이지로 이동할 필요가 없습니다.
- **전체 대화**를 누르면 같은 화면에서 대화 기록을 크게 볼 수 있습니다.
- 카페 바닥을 탭해 이동하거나 반투명 방향키를 사용하세요.
- 동작 버튼을 가로로 밀어 음료, 인사, 하트, 건배를 사용하세요.
- 상단의 **초대 ↗** 버튼으로 친구에게 방 링크를 보내세요.
- PC에서는 기존 카페 + 오른쪽 채팅창 디자인을 유지합니다.

## 알려진 제한

- 방당 최대 24명. 방에 비밀번호/관리자 기능은 없습니다.
- 채팅 최근 60개만 서버 메모리에 유지되고, 재시작하면 초기화됩니다.
- Render 무료 서버는 절전 모드가 있어 접속이 지연될 수 있습니다.
- 인터넷 실시간 접속은 Render 등 Node.js + WebSocket 지원 서버에 배포해야 합니다.
